<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server JSON response -> React state | The endpoint response (including `nextPageToken`) drives a client loop. |
| Browser -> `POST /api/sync/hotmart` | User-triggered writes to the sales database. |
| Rendered strings -> DOM | Server-provided error text is displayed to the user. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-14 | Denial of Service | Client pagination loop in `DashboardHeader.tsx` | mitigate | Hard `MAX_IMPORT_PAGES = 200` iteration cap plus a `break` when `nextPageToken` is null, so a repeating or malformed cursor cannot produce an unbounded request storm against the app or the Hotmart API. |
| T-06-15 | Denial of Service | Duplicate concurrent imports | mitigate | `disabled={isImporting}` on the button plus an early `return` in `handleImportHistory` when `isImporting` is true, so overlapping import loops cannot be started. |
| T-06-16 | Information Disclosure | Error rendering | mitigate | Only the fixed `error` strings defined in the 06-02 HTTP contract are displayed; upstream Hotmart bodies never reach the client (enforced server-side in plan 06-02), so no token or buyer PII can surface in the UI. |
| T-06-17 | Cross-Site Scripting | Progress/error text | mitigate | All server-supplied text is rendered as React children (auto-escaped). No `dangerouslySetInnerHTML` is introduced; the progress width is a numeric template clamped with `Math.min(100, ...)`. |
| T-06-18 | Information Disclosure | Client bundle | mitigate | `DashboardHeader.tsx` is a `'use client'` module and must never read `process.env.HOTMART_ACCESS_TOKEN`; the credential is used exclusively in the server route. |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs NO packages — `lucide-react`, `react` and Tailwind are already dependencies. No `npm install` is permitted; escalate instead of installing. |
</threat_model>
