  <action>
    Em `src/lib/hotmart.ts`:

    1. Adicionar dois campos à interface `HotmartSaleRow`, após `created_at`:
       `product_id: string | null;` e `product_name: string | null;`
    2. Criar uma função interna (NÃO exportada, junto dos outros helpers privados) com a assinatura
       `function extractProduct(record: Record<string, unknown>, purchase: Record<string, unknown>): { product_id: string | null; product_name: string | null }`.
       Ordem de resolução, usando os helpers já existentes `asRecord` e `toCleanString`:
       - `const product = asRecord(record.product ?? purchase.product);`
       - `product_id = toCleanString(product.id) ?? toCleanString(product.ucode) ?? toCleanString(record.product_id) ?? null;`
       - `product_name = toCleanString(product.name) ?? toCleanString(record.product_name) ?? null;`
       `toCleanString` já converte números finitos em string, então `product.id: 123` vira `"123"`.
    3. Em `mapHotmartItem`, chamar `extractProduct(record, purchase)` e incluir `product_id` e `product_name` no objeto `sale` retornado. NÃO alterar nenhuma outra regra de mapeamento (transaction_id, status, price, created_at, utms permanecem idênticos).

    Em `scripts/check-hotmart-mapping.mjs`, acrescentar um novo bloco de assertions no mesmo estilo dos blocos existentes (chaves `{ ... }` + `assert` do `node:assert/strict`), cobrindo:
    - produto no topo do item: `{ product: { id: 123, name: 'Curso X' }, purchase: { transaction: 'HP-P1', status: 'approved', price: { value: 10 } } }` → `product_id === '123'`, `product_name === 'Curso X'`.
    - produto aninhado em purchase: `{ purchase: { transaction: 'HP-P2', product: { id: 'ABC', name: 'Curso Y' }, status: 'approved', price: { value: 10 } } }` → `product_id === 'ABC'`, `product_name === 'Curso Y'`.
    - fallback por ucode: `{ product: { ucode: 'u-9', name: '  Curso Z  ' }, purchase: { transaction: 'HP-P3' } }` → `product_id === 'u-9'`, `product_name === 'Curso Z'` (trim).
    - ausência de produto: `{ purchase: { transaction: 'HP-P4', status: 'approved', price: { value: 10 } } }` → `product_id === null` e `product_name === null`, e o resultado NÃO é null.

    Não remover nem alterar assertions já existentes.
  </action>
