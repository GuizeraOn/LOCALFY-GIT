<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Servidor → navegador (`/api/products`) | Nomes de produtos vindos do banco renderizados na UI |
| Navegador → `/api/metrics` | `productId` escolhido pelo usuário é enviado na query string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-20 | Tampering | `ProductFilter` (render de nomes) | mitigate | Nomes renderizados como texto React (`{p.name}`), com escape automático; `dangerouslySetInnerHTML` proibido e verificado por grep no gate da Task 1 |
| T-07-21 | Tampering | montagem da URL em `page.tsx` | mitigate | `encodeURIComponent(productId)` impede injeção de parâmetros extras na query string; o servidor revalida com allowlist (T-07-14) |
| T-07-22 | Information Disclosure | dropdown de produtos | accept | Lista de produtos tem a mesma sensibilidade das métricas já exibidas; app sem autenticação de usuário nesta versão (limitação herdada das Phases 1-6) |
| T-07-23 | Denial of Service | `ProductFilter` | mitigate | Painel com `max-h-80 overflow-y-auto`; lista limitada no servidor (`.limit(20000)` + dedupe), evitando render de lista ilimitada |
| T-07-24 | Repudiation | troca de filtro | accept | Ação de leitura sem efeito colateral no banco; não requer trilha de auditoria |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | Nenhum pacote novo instalado — `swr`, `lucide-react` e `date-fns` já estão em `package.json`; install descoberto durante a execução exige checkpoint humano bloqueante |
</threat_model>
